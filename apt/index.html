RALS APT Repository

This is the APT repository for RALS packages.

Directory Contents

  • dists/ - Distribution packages
  • pool/ - Package pool

Available Distributions

  • Ubuntu 20.04 (focal)
  • Ubuntu 22.04 (jammy)
  • Debian 12 (bookworm)
  • Debian 11 (bullseye)
  • Ubuntu 24.04 (noble)

Installation Instructions

To use this repository, add the following to your sources.list:

# For Ubuntu 20.04 (focal)
echo "deb [arch=amd64,arm64] https://repo.rals.space/apt/ focal main" | sudo tee /etc/apt/sources.list.d/rals-space.list

# For Ubuntu 22.04 (jammy)
echo "deb [arch=amd64,arm64] https://repo.rals.space/apt/ jammy main" | sudo tee /etc/apt/sources.list.d/rals-space.list

# For Ubuntu 24.04 (noble)
echo "deb [arch=amd64,arm64] https://repo.rals.space/apt/ noble main" | sudo tee /etc/apt/sources.list.d/rals-space.list

# For Debian 11 (bullseye)
echo "deb [arch=amd64,arm64] https://repo.rals.space/apt/ bullseye main" | sudo tee /etc/apt/sources.list.d/rals-space.list

# For Debian 12 (bookworm)
echo "deb [arch=amd64,arm64] https://repo.rals.space/apt/ bookworm main" | sudo tee /etc/apt/sources.list.d/rals-space.list

Then add the GPG key and update:

curl -fsSL https://repo.rals.space/KEY.gpg | sudo gpg --dearmor -o /etc/apt/trusted.gpg.d/rals-space.gpg
sudo apt update
sudo apt install rals-agent
