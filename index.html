RALS Packages

RALS monitoring agent packages for various Linux distributions.

Debian/Ubuntu (.deb)

Install RALS Agent on Debian and Ubuntu systems:

curl -fsSL https://repo.rals.space/KEY.gpg | sudo gpg --dearmor -o /etc/apt/trusted.gpg.d/rals-space.gpg
echo "deb [arch=amd64,arm64] https://repo.rals.space/apt/ focal main" | sudo tee /etc/apt/sources.list.d/rals-space.list
sudo apt update && sudo apt install rals-agent

Browse APT repository

RHEL/CentOS/Fedora (.rpm)

Install RALS Agent on RHEL, CentOS, and Fedora systems:

sudo rpm --import https://repo.rals.space/RPM-GPG-KEY-rals-space
sudo tee /etc/yum.repos.d/rals-space.repo << EOF
[rals-space]
name=RALS Space
baseurl=https://repo.rals.space/rpm/rhel-8/\$basearch/
enabled=1
gpgcheck=1
gpgkey=https://repo.rals.space/RPM-GPG-KEY-rals-space
EOF
sudo dnf install rals-agent

Browse RPM repository
